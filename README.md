# 🧳 Tourism Management System – Incredible India 🇮🇳

🔗 **Project Working Demo:**  https://teesha-hub.github.io/Tourism_Website/

A full-stack **Tourism Management System** focused on **Indian tourism**, developed as an academic project.  
The system allows users to explore and book tour packages while providing admins with complete management control.

---

## ✨ Features

### 👤 User Module
- User registration and login
- Browse tour packages
- Book tour packages
- Make payments
- View booking and payment status

### 🧑‍💼 Admin Module
- Secure admin login
- Add, update, and delete tour packages
- Manage users, bookings, and payments

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  

---

## 🧩 System Design

The project is designed using an ER diagram consisting of:
- Users
- Admins
- Tour Packages
- Bookings
- Payments  

All modules are connected to ensure smooth data flow between frontend and backend.

---

## 🎯 Project Objective

- Apply database design concepts using ER diagrams  
- Build a complete frontend–backend web application  
- Implement authentication and role-based access  
- Create a visually appealing and responsive UI
